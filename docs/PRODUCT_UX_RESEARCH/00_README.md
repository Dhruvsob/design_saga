# Design Saga — Product & UX Research Package

Status: **in progress** (research phase; no redesign code is written from this
package until the owner reviews the blueprint). Started 06/11/2026.

This package is the evidence base for reorganising the existing ERP. It reuses
and links existing documents instead of repeating them:

| Existing document | Use here |
|---|---|
| `docs/planning/01-existing-erp-audit.md` | earlier module audit (baseline, may be stale) |
| `docs/planning/04-existing-module-enhancement-plan.md` | earlier enhancement ideas |
| `docs/planning/09-user-journey-workflow-matrix.md` | persona journeys |
| `docs/CORRECTION-CAPABILITY-MATRIX.md` | Edit/Delete/Correct status per record type |
| `DESIGN-SAGA-REPAIR-TRACKER.md` | canonical fix backlog (DS-xxx); this package feeds it |

## Rules followed

- A finding cites its evidence (file, route, count or screenshot). Anything not
  opened in a browser is marked **not inspected**.
- References are recorded with URL and date, and only as patterns to adapt —
  no copying of branding, assets or layouts.
- Existing product refinement (Plan A) comes before new features (Plan B).
